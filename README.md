# Портфолио

Личный сайт-портфолио. Статика: чистый HTML + CSS, без сборки и зависимостей.

## Локально

Открыть `index.html` в браузере — этого достаточно.

## Публикация (GitHub Pages)

Размещается в репозитории GitHub, страница — основная ветка (`main`), корень.
Настройки: **Settings → Pages → Source: Deploy from a branch**.

## Структура

- `index.html` — главная одностраничник (работы, опыт, контакты)
- `works/*.html` — страницы кейсов
- `assets/style.css` — общий стиль
